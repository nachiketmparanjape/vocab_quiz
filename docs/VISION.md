## Purpose

Make personal vocabulary stick: import the words you actually need, get
quizzed on a spaced schedule, and watch every word climb from new to
mastered.

## V1 scope (as imported 2026-10-09)

- CSV word upload + word lists
- Flashcard + multiple-choice quiz modes, configurable word count
- SM-2 spaced repetition with ease-factor adjustment
- Per-word mastery levels (new → learning → familiar → mastered) + dashboard
- Google sign-in

Founder has not set v1 scope in-studio yet — the above describes the app as
imported. Scope changes go through sprint planning.

## Explicit non-goals (imported state; founder to confirm)

- No AI-generated content (words are user-supplied, unlike fluencia)
- No grammar, reading, or lesson structure
- No audio/pronunciation
- No pre-built word packs

## The one-line test

A user imports a 200-word list, does a 5-minute review session daily, and the
dashboard shows words moving into "mastered" every week. Anything that
doesn't serve that loop is out.
